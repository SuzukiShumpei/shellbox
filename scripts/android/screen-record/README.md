# adbコマンド 画面収録（MP4 or GIF）

- エミュレーターでの画面収録開始
- エミュレーターでの画面収録停止
- 画面収録ファイル名の設定
- 画面収録ファイル名のMP4, GIF指定（両方指定も可能）
- エミュレーターから今回分のファイルの削除

## 事前準備

- ffmpegをインストールする: `brew install ffmpeg` (Macの場合)
- 1台だけエミュレーターを起動しておく（複数台起動していると失敗するので注意）
- 実行pathにoutputディレクトリが作成されるので、Git管理されていないpathを設定しておくことを推奨

## 使い方

1. 画面に表示される通りに進めればOK。 
2. エミュレータの仕様上、画面収録を開始してから何も操作しないとエラーになるので注意。
