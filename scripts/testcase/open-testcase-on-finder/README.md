# 該当テストケースフォルダをFinderで開く

## 概要

- 入力したテストケースIDにヒットしたテストケースフォルダを Finder で開く
- 複数部分一致する場合は選択肢を表示する

## 事前準備

- `resona-smart-app-api-mock` リポジトリを clone しておくこと
- clone したディレクトリ名は元の `resona-smart-app-api-mock` のままであること
- 実行 path を `resona-smart-app-api-mock` ディレクトリのルートに設定すること

## 使い方

1. 上記のとおり実行 path を設定する。
2. 画面に表示される通りに進めれば OK。
